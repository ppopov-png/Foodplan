# Foodplan
Адаптивный мини-сайт с семейным меню на неделю.

## Возможности
- Дни недели, 4 приема пищи ежедневно
- Нажатие на блюдо открывает ингредиенты, рецепт, время и приблизительную калорийность
- Перекусы для учебы
- Мобильная верстка, без сборки и зависимостей

## Публикация
GitHub Actions автоматически публикует сайт на GitHub Pages при push в main.
Если это первый деплой: Settings → Pages → Build and deployment → Source: **GitHub Actions**.
URL после публикации: https://ppopov-png.github.io/Foodplan/

Калорийность приблизительная. Для беременных калории не ограничиваются; скоропортящиеся блюда хранить охлажденными.
